# 稀疏引导核查：当前 CoCoGen 与论文的关系

## 结论

当前正式评估使用了稀疏观测引导，具体是基于 CoCoGen 附录 D 的观测回填与 RePaint，并采用为 FM4PDE 数据适配、正式前冻结的短采样配置。它不是论文正文中通过稀疏观测训练的 ControlNet 条件模型。两条路线在论文中均有依据；缺少观测条件训练本身，不能证明附录 D 路线必然表现差。

2026-09-16 对 Darcy 全部九个稀疏单元、9,000 次任务评估、288 个预测文件进行了 CPU 复核。所有有效观测点的预测均与观测真值逐值相等，所有保存的逐样本误差与 CPU float64 重算一致。因此，目前全场误差较高确实来自未观测区域的重建，不能解释为没有接入稀疏观测。

## 实际使用了哪些观测

三种分布 ID、smooth、rough 均采用下列设置：

| 任务 | 系数场 a 的观测点数 | 解场 u 的观测点数 | 观测点最大绝对误差 |
|---|---:|---:|---:|
| sparse_forward | 500 | 0 | 0 |
| sparse_inverse | 0 | 500 | 0 |
| sparse_joint | 500 | 500 | 0 |

计数对每例分别核验，预测文件哈希、原始 FM4PDE 输入与有效掩码、样本 ID、模型阶段、选定权重标识、归一化、物理配置和实际 NFE 均匹配。9,000 为任务评估次数，同分布不同任务复用样本编号。

当前实现并非只在最后覆盖观测点。在每次反向采样中，它把观测按当前噪声时间生成对应的 VP 扩散边缘样本，写入观测位置；未知区域通过网络预测更新。每个时间间隔还额外进行四次 RePaint 前向加噪与反向去噪，以传播观测信息。最终恢复无噪声的精确观测值。对应实现见 [sampler.py](../cocogen_eval/sampler.py) 的 `marginal`、`sample`，任务观测屏蔽见 [main_inputs.py](../cocogen_eval/main_inputs.py)。

该检查逐批加载真实预测与原始观测，没有重新采样或占用 GPU。复核器为 [validate_saved_batches.py](../cocogen_eval/validate_saved_batches.py)，报告保存其源文件哈希。该脚本也可在 NS 首批结果产生后执行；当前的通过证据只覆盖 Darcy 九个稀疏单元。

## 原文支持稀疏引导的两条路线

参考原文 [CoCoGen，arXiv:2312.10527v2](https://arxiv.org/html/2312.10527v2)。

1. **正文第 5.2.1 节与附录 C.1：学习条件模型。**训练时随机选择压力传感器位置与数量，把压力观测作为条件，学习压力场重建和渗透率反演；图 8 使用 250 个压力观测。原文写道：“We train a conditional augmentation to perform probabilistic field inversion and reconstruction from sparse measurements.” 服务器现有 Darcy 训练代码返回常数标签 0，条件编码器输入维度为 1，没有提供此类观测条件训练。
2. **附录 D、表 3/4 与图 12：无额外条件训练的近似采样。**利用已有联合场 score 模型，通过观测回填近似条件分布，再用 RePaint 改善观测区域与未知区域的协调。原文指出单纯回填可能产生区域不协调和较高物理残差，并报告 RePaint 改善重建；其附录实验的重建表现甚至优于正文 ControlNet，但计算成本更高。

原文同时讨论了稀疏反演的条件不确定性：给定少量压力观测，完整压力与渗透率场未必唯一。它展示了多次生成的均值与标准差。因此，符合观测、符合 PDE 与恢复某个指定真值是不同的检查。不过，当前相对 FM4PDE 的系统性误差差距，不能仅凭这一点解释。

## 当前结果为什么仍可能与真值相差很大

以下差异已确认，但尚未通过控制变量实验分离各自贡献：

| 项目 | 论文附录 D 的 Darcy 实验 | 当前 FM4PDE 适配评估 |
|---|---|---|
| 时间间隔数 | 2,000 | 100 |
| RePaint | 比较额外 r=1/2/3/5/10 | 固定额外 r=4 |
| 网络评估次数 | 例如 r=3 为 8,000，r=5 为 12,000 | 500 |
| 网格 | 64×64 | 128×128 |
| 500 个传感器占单场比例 | 12.21% | 3.05% |
| 数据与任务 | 原文 s=16 Darcy 数据，稀疏压力观测 | FM4PDE 三种分布及五种任务，现有服务器权重 |
| 误差定义 | 表 3/4 使用重建误差的平方 L2 | 物理空间逐例相对 L2 后取均值 |

缩短到 100 时间步是正式启动前为满足四模型约一天预算做出的选择。更粗的时间离散和更少的网络评估可能削弱条件信息传播，但尚未证实它是当前误差的主因，也不能承诺增加步数就能解决。论文的 500 点与当前 500 点覆盖比例不同，且数据分布不同；两套误差数值不能直接互比。

当前物理修正仅直接更新解场 u，并保持观测不变，不直接优化系数场 a。它可以改善 PDE 残差，却不能保证恢复真实系数。例如 Darcy ID 稀疏反问题已经满足所有 500 个压力观测，但系数相对 L2 仍为 62.43%；稀疏联合重建的系数和解误差分别为 53.03% 与 16.10%。这些是完整单元均值，见 [Darcy 完整结果](darcy_complete_results_20260915.md)。

因此，本次结果应明确标注为 **CoCoGen Appendix-D + RePaint，现有权重、FM4PDE 适配、500 NFE**。它揭示当前配置在稀疏任务上重建不足；它既不能代表正文观测条件模型的实测结果，也不足以否定论文报告的稀疏引导能力。若要评估正文路线，需要使用按稀疏观测训练的条件权重。正式单元继续保持原冻结配置。
