## 论文依据与适用范围

参考 Jacobsen、Zhuang、Duraisamy 的 [CoCoGen，arXiv:2312.10527v2](https://arxiv.org/abs/2312.10527v2)，特别是第 3 节和附录 D。

论文区分了两条条件生成路线：

1. 正文中的观测条件模型：用传感器观测训练条件网络。
2. 附录 D 的 data imputation：用已训练的 score 模型、观测量的前向 VP 扩散边缘分布、反向 SDE 和 RePaint 完成条件生成。

197 上已有 ControlNet 权重训练时仅输入常数 PDE 编号，不能解释为学习了观测条件的正文模型。本次采用附录 D 路线，同时在独立校准集上比较基础模型与这些 ControlNet 权重。

附录 D 使用 Euler–Maruyama、2,000 个时间间隔、最后 50 步物理修正及 10 步后处理。文中的 `r` 是每个时间间隔 **额外** 的前向/反向循环数。因此本实现每样本 NFE 为 `steps × (1 + repaint)`。例如 2,000 步、`repaint=1` 为 4,000 次网络调用。

## 已发现的问题与处理

旧服务器源文件逐文件保存于 `reference/server197_20260915/`，原服务器实验文件保持原位。

| 问题 | 影响 | 本次处理 |
|---|---|---|
| 在时间网格最后一点继续减一步 | 前向方差可能在负时间开方，出现 NaN | 以正时间评估网络，严格走到 0；观测在 0 时恢复原值 |
| RePaint 分支错误调用 `self.g` | 部分分支运行失败 | 直接使用 VP 扩散系数 |
| PF ODE 构造器位置参数错位 | 重采样次数可能被错误放大 | 附录 D 采样器独立实现，参数以名称记录 |
| 物理采样器覆盖传入条件并清零 | 非 Darcy 的 ControlNet 与训练条件不符 | 传入各 PDE 训练时的固定编号 |
| 旧 `[p,k]` 假设与服务器 `[a,u]` 数据顺序不符 | 观测、指标和物理修正通道可能颠倒 | 整个评估采用 `[a,u]`；Burgers 为单通道完整时空场 |
| 用 pressure 的均值/方差还原整个张量 | 系数场与解场的物理单位错误 | 分通道恢复原训练统计，分通道归一化/反归一化 |
| 配置中给出的物理修正步长未被使用 | 调参无效、结果难复现 | 将修正次数、更新上限和回溯次数全部写入配置与收据 |
| float32 上以 `1e-8` 作数值差分，且只用对角导数 | 消减误差、缺少邻点对总残差的贡献 | 对完整离散残差平方和进行自动微分 |
| 用带符号最大梯度归一化，缺少零梯度保护 | 步长异常、修正可能增大残差 | 用最大绝对梯度、零梯度保护和逐样本回溯下降 |
| 原作者问题与 FM4PDE 的源项、网格和边界不一致 | 残差不能代表当前数据的 PDE | 冻结 FM4PDE 的物理算子和边界配置，仅复用评估定义 |
| 旧样例没有完整样本/观测/权重关联 | 无法构成可配对主实验 | 使用归档的正式输入、观测 mask、样本 ID，并保存权重与结果哈希 |

物理修正默认只更新解通道，这与论文 Darcy 方法一致。对全观测解的逆问题，该修正不会更改观测值，也不会额外改变系数通道。`all` 通道和精确 VP 重加噪接口被明确视为扩展，本轮默认网格未启用。

最大绝对梯度归一化、自动微分和回溯是对残差下降的数值实现修正。FM4PDE 物理算子是针对当前基准的适配。因此应将结果描述为“基于 CoCoGen 附录 D 的修正与适配”，不能声称逐行复现原论文实验。

## 输入与公平性

- 正式样本、掩码、分布、任务复用 FM4PDE 的冻结输入目录 `outputs/pretrained/resume_main_20260911/evaluation_inputs`。
- 四个 PDE 各有 ID / smooth / rough × sparse_forward / sparse_inverse / sparse_joint / full_forward / full_inverse，共 60 单元。
- 正式 ID 为 `0..999`；NS 为 `2000..2999`。稀疏观测每个活动场 500 点，全观测为 128×128。保留原主实验中 shared-mask 设置的例外，直接读取历史 mask。历史文件同时保存两个场的候选 mask；FM4PDE 在观测损失中按 task 屏蔽非活动场。本适配在输入端做同样的屏蔽，避免 forward 额外看到解观测，或 inverse 额外看到系数观测。
- 原训练归一化从各 PDE 的 50,000 个训练样本恢复；不使用正式测试集统计。保留 sample std 的 correction=1 和原训练的 `std+1e-8`。
- 每个 PDE 另取 ID 文件的 `1000..1095` 作为校准与验证池。这些是未进入正式评估的测试文件行，应明确称为“独立留出的 ID 校准样本”，不是训练集。
- `1000..1031` 用于配置选择；`1032..1095` 在配置冻结后用于验证，不根据后者重新调参。不同分布使用同一 PDE 的冻结配置。
- 模型采样接口只接收观测值和 mask；未观测位置在进入采样器时再次清零。完整真值仅在采样结束后计算误差。
- 随机数按 PDE、seed、样本 ID 派生独立流；改变分批不会改变该样本的随机数。算子浮点舍入仍可能随批量变化，正式批量与 TF32 状态会留档。
- 指标为物理空间逐样本相对 L2，再对 1,000 个样本汇总；同时保留每样本误差、配对 FM4PDE 差值、PDE 残差、真值残差、实际 NFE 和耗时。
- NS 沿用主实验的 endpoint_secant 残差，属于两端点近似，不能解释为完整轨迹的 PDE 一致性。
