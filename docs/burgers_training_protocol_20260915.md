## 模型与训练

- 复用服务器 CoCoGen 的 UNET1，输入/输出改为 1 个完整时空通道，数据顺序为 `[batch,1,time,space]`，分辨率 128×128，`n_feat=256`、`pool_size=4`。
- 使用基础 score 模型，不添加仅接收 PDE 常数标签的 ControlNet。
- VP 的 `beta_min=1e-4`、`beta_max=10`，时间从 `(1e-5,1]` 均匀采样。
- 损失保持原 CoCoGen 的逐像素求和：`mean_batch(sum_pixels((score*std+noise)^2))`。同时记录除以 16,384 后的每像素损失，避免把三/四位数损失直接当成预测误差。
- AdamW：学习率 `1e-4`、weight decay `0.01`；float32，TF32 开启。
- 计划两张 GPU 做 DDP，每卡 batch 最多 32、全局 batch 最多 64。实际训练前先测 batch 1→4→8→16→32 的前向、反向和优化器峰值显存，根据实测峰值保守筛选下一档，采用实际通过测速的最大安全批量（至少 8）。最终批量及每轮耗时估计写入训练配置。
- 每轮重新打乱训练样本。至少训练 300 轮、最多 1,200 轮；每 10 轮检查固定验证面板，连续 20 次检查未达到相对于参考值 0.2% 的改善时，在满足至少 300 轮后停止。
- 每轮保存可恢复的 `last.ckpt`；固定验证损失改善时保存 `best.ckpt`；每 100 轮保留独立快照。保留模型、优化器、各 rank 的 Python/NumPy/PyTorch CPU/CUDA 随机状态、归一化统计、代码和数据标识。

## 数据隔离

训练样本来自五个原始训练分片，共 50,000 个。均值与 sample std 从训练样本恢复，归一化除以 `std+1e-8`；缓存建立时逐分片复核原始 float32 字段哈希。

三个测试文件 ID 段的用途严格分离：

| ID 文件内的样本行 | 用途 |
|---|---|
| `0..999` | 正式主实验；ID、smooth、rough 各两种观测设置 |
| `1000..1095` | 采样配置的选择与独立验证 |
| `1096..1351` | 仅选择训练 checkpoint 的固定验证面板 |

后两组是从未进入正式评估的 ID 测试文件行中留出的面板，不应称为原始训练集。固定验证分别检查均匀随机时间与 `t=0.001/0.01/0.1/0.5/1`，报告每像素和求和损失；不会把这些数据加入优化器更新。
